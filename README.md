# **Teste Prático - Desenvolvedor Backend - Target**

Este repositório contém as soluções para o teste prático de desenvolvedor backend. As soluções foram implementadas em **Node.js** e estão organizadas dentro da branch `develop`.

---

## **Pré-requisitos**
Certifique-se de ter as seguintes ferramentas instaladas no seu ambiente:
- **Node.js** (versão 14 ou superior)
- **Git**

---

## **Instruções para execução**
As soluções estão localizadas na branch `develop` e organizadas em arquivos individuais dentro da pasta `teste_target/testes`. Siga os passos abaixo para executar cada exercício:

### 1. **Clone o repositório**
Faça o clone do repositório para sua máquina local:
```bash
git clone <https://github.com/GiovanniM3n0n/teste_target.git>
```

### 2. **Navegue para a branch `develop`**
Confira a branch onde estão as soluções:
```bash
git checkout develop
```

## **Descrição dos exercícios e como executá-los**

### **Exercício 1: Soma até um índice**
- **Arquivo**: `teste_target/testes/teste_1.js`
- **Descrição**: Calcula a soma dos números de 1 até o índice especificado.
- **Execução**:
  ```bash
  node teste_target/testes/teste_1.js
  ```

---

### **Exercício 2: Verificar número na sequência de Fibonacci**
- **Arquivo**: `teste_target/testes/teste_2.js`
- **Descrição**: Calcula a sequência de Fibonacci e verifica se um número informado pertence à sequência.
- **Execução**:
  ```bash
  node teste_target/testes/teste_2.js
  ```
  Durante a execução, será solicitado que você insira um número no terminal.

---

### **Exercício 3: Análise de faturamento diário**
- **Arquivo**: `teste_target/testes/teste_3.js`
- **Dados**: Localizados no arquivo `teste_target/data/dados.json`.
- **Descrição**:
  - Calcula:
    - O menor valor de faturamento diário.
    - O maior valor de faturamento diário.
    - O número de dias com faturamento superior à média mensal.
  - O script lê os dados diretamente do arquivo JSON.
- **Execução**:
  ```bash
  node teste_target/testes/teste_3.js
  ```
  Certifique-se de que o arquivo `dados.json` está na pasta correta (`teste_target/data`).

---

### **Exercício 4: Percentual de faturamento por estado**
- **Arquivo**: `teste_target/testes/percentual_faturamento.js`
- **Descrição**: Calcula o percentual de representação de cada estado no faturamento total.
- **Execução**:
  ```bash
  node teste_target/testes/percentual_faturamento.js
  ```

---

### **Exercício 5: Inversão de string**
- **Arquivo**: `teste_target/testes/inverter_string.js`
- **Descrição**: Inverte os caracteres de uma string informada pelo usuário, sem utilizar funções prontas.
- **Execução**:
  ```bash
  node teste_target/testes/inverter_string.js
  ```
  Durante a execução, será solicitado que você insira uma string no terminal.
